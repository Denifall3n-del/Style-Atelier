# Style Atelier - школа стиля (RU/EN)

Образовательный сайт о стиле одежды: цветовые гармонии, типы фигуры, стили,
сочетания и аксессуары, капсульный гардероб, квизы и конструктор образа
с разбором "почему это работает". Два языка (русский/английский) с
переключателем в шапке.

## Структура

- `index.html` - главная
- `colors.html` - цвет: гармонии, 60-30-10, подтон кожи, 12 сезонов
- `figure.html` - фигура: 10 типажей, посадка, рост
- `styles.html` - 7 стилей одежды
- `combinations.html` - сочетания и аксессуары (12 тем)
- `capsule.html` - капсульный гардероб 4x4
- `quiz.html` - квизы: подтон, фигура, стиль
- `builder.html` - конструктор образа на манекене + движок анализа
- `css/style.css` - общая дизайн-система
- `js/common.js` - переключение языков, навигация, анимации
- `research/` - исследовательские материалы (5 отчетов)

Сайт полностью статический: нет сборки, нет бэкенда. Единственная внешняя
зависимость - шрифты Google Fonts (с системными запасными шрифтами).

## Как опубликовать на GitHub Pages

1. Создайте новый публичный репозиторий на github.com (например, `style-atelier`).
2. Загрузите в него ВСЕ файлы и папки из этой папки (`index.html`, остальные
   `.html`, папки `css/`, `js/`), сохраняя структуру. Проще всего: кнопка
   "uploading an existing file" на странице репозитория и перетащить файлы.
   Папку `research/` загружать не нужно (это черновики).
3. В репозитории откройте Settings -> Pages.
4. В разделе "Build and deployment" выберите Source: "Deploy from a branch",
   Branch: `main`, папка `/ (root)`. Нажмите Save.
5. Через 1-2 минуты сайт будет доступен по адресу
   `https://<ваш-username>.github.io/style-atelier/`.

## Локальный просмотр

Просто откройте `index.html` в браузере двойным кликом. Все работает
без сервера (переключение языков хранится в localStorage).
